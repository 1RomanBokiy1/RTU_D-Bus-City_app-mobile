# D-Bus City
### Российский Технологический Университет МИРЭА (RTU)
---
## Описание приложения

**D-Bus City** — мобильная образовательная игра, разработанная на движке Godot Engine для ОС Аврора. Игрок проходит игровые уровни, отвечает на вопросы и поддерживает счастье пользователей. По мере прохождения открываются новые этапы развития городской среды и отображается достигнутый прогресс.

---
## Цели проекта
Проект разработан в рамках прохождения практики с целью создания мобильного игрового приложения для ОС Аврора на движке Godot Engine для ознакомления работы системы D-Bus для разработчиков на OS Android. Проект демонстрирует возможности разработки мобильных игр с использованием Godot, создания пользовательского интерфейса, игровых механик и системы сохранения результатов.

---
## Функционал приложения
- прохождение игровых уровней;
- выбор ответов на вопросы;
- система жизней;
- развитие виртуального города;
- сохранение результатов игрока;
- таблица рекордов (Hall of Fame);
- экран настроек;

---
## Список используемых технологий
- Godot Engine 4.4;
- GDScript;
- встроенная система UI Godot;
- встроенная система анимации Godot;
- встроенная система управления сценами и ресурсами Godot.

## Подробное описание приложения
Игровой процесс состоит из последовательного прохождения уровней. На каждом уровне пользователю предлагается выполнить задание и выбрать правильный вариант ответа. За успешное прохождение игрок получает возможность развивать виртуальный город и наблюдать изменения городской среды.

В приложении реализованы:
 - механика сохранения результатов;
 - система подсчёта достижений;
 - механика жизней;
 - система настроек;
 - таблица рекордов.

Интерфейс адаптирован для мобильных устройств и сенсорного управления.

---
## Совместимость
Приложение разработано на Godot Engine 4.4 для архитектуры aarch64.

Поддерживаемые устройства:
- устройства под управлением ОС Аврора с архитектурой ARM64
- эмулятор ОС Аврора

## Особенности сборки
Общие рекомендации по сборке приложений для ОС Аврора:
https://developer.auroraos.ru/doc/software_development/guides/port_apps/godot_export
https://wiki.pmifi.ru/ru/guides/godot-aurora

Для сборки проекта потребуется:
  - Операционная система Ubuntu Desktop 22.04 и выше или Alt Linux
  - Godot Engine 4.4 от Ярослава Андреева
  - Aurora SDK MB2
  - Настроенная среда сборки Aurora OS (Подробная инстуркция - https://wiki.pmifi.ru/ru/guides/godot-aurora)

Дополнительные серверы или внешние сервисы не требуются.

---
## Установка и запуск
1. Клонировать репозиторий на ОС Ubuntu 22.04 и выше или Alt Lunix;
2. Открыть проект в Godot Engine 4.4. от Ярослава Андреева;
3. Выполнить экспорт приложения для Aurora OS; (Подробная инструкция - https://wiki.pmifi.ru/ru/guides/godot-aurora)
4. Установить rmp файл на устройство или эмулятор;
5. Запустить приложение.

Дополнительных условий для запуска не требуется.
